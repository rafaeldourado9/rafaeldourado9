<div align="center">

```
┌──────────────────────────────────────────────────────────────────┐

│   1. Functional Requirements     →  what the system must do     │
│   2. Non-Functional Requirements →  latency · throughput · SLA  │
│   3. Capacity Estimation         →  QPS · storage · bandwidth   │
│   4. Data Modeling               →  entities · relations · idx  │
│   5. API Design                  →  contracts between services  │
│   6. System Design               →  where each component lives  │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
```
